# RIndex

> Digital Vulnerability Assessment Platform

RIndex is a web-based application that analyzes digital security habits and simulates potential attack paths to estimate a user's overall online vulnerability.

The platform combines concepts from:
- Cryptography
- Discrete Mathematics
- Automata Theory
- Number Systems
- Probability & Risk Modeling

to visualize how small security weaknesses can lead to larger account compromise risks.

---

## Features

- Digital vulnerability assessment
- Dynamic “Hackability Score”
- Password entropy analysis
- Attack path visualization
- Phishing awareness testing
- Account exposure simulation
- Interactive risk dashboard
- Real-time security recommendations

---

## Core Concepts

### Cryptography
Used for:
- Password entropy calculations
- Hash visualization
- Brute-force estimation
- Authentication security analysis

### Discrete Mathematics
Used for:
- Graph-based attack path modeling
- Relationship mapping between vulnerabilities
- Risk propagation analysis

### Automata Theory
Used for:
- User risk state transitions
- Security event simulation
- Attack progression modeling

### Number Systems
Used for:
- Binary and hexadecimal visualization
- Bit-level entropy representation
- Hash formatting and analysis

## Project Goal

The goal of RIndex is to demonstrate how mathematical and computational concepts can be applied to a real-world cybersecurity problem through an interactive web application.

Rather than performing real hacking or penetration testing, the platform focuses on:
- educational simulations,
- risk modeling,
- visualization of vulnerabilities,
- and security awareness.
